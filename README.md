# 🎓 Student Performance Predictor

A Machine Learning web application that predicts a student's GPA based on academic and lifestyle factors.

## Features

- Predict GPA using Random Forest
- Student Dashboard
- Performance Category
- GPA Progress Bar
- Personalized Recommendations
- Feature Importance
- Prediction History
- Download Prediction History (CSV)

## Technologies

- Python
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib
- Joblib

## Dataset

2000 student records with:
- Study Hours
- Sleep Hours
- Social Hours
- Physical Activity
- Stress Level
- GPA

## Machine Learning Model

Random Forest Regressor

## How to Run

pip install -r requirements.txt

streamlit run app.py
